# Changelog

## 0.4.0

- Ajout d'un explorateur de zones Alliance avec filtre de recherche.
- Sauvegarde persistante de l'état exploré pour chaque zone.

- Maintien des avertissements pour les données indicatives au-delà du niveau 30.

- Correction de l'updater Windows pour les chemins de fichiers.
